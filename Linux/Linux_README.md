## Topics covered

- Kernel vs shell, Linux architecture, distributions, user types
- Files and directories, viewing and editing files
- Redirection and pipes (`>`, `>>`, `|`)
- Text processing: `grep`, `sed`, `awk`, `cut`, `sort`, `uniq`, `wc`
- Permissions and ownership (`chmod`, `chown`, `umask`)
- Processes, disk and memory, archives and compression
- Networking and data transfer, packages and services
- Cron scheduling, logs and troubleshooting
- Real data-engineering one-liners
- 25 interview questions with short answers
