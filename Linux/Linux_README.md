Concise, interview-ready Linux notes for aspiring data engineers. They cover the fundamentals and the commands used most in day-to-day data work, along with common interview questions.

- Linux fundamentals: kernel, shell, architecture, users
- Files, directories and permissions
- Redirection and pipes
- Text processing with `grep`, `sed`, `awk`, `cut`, `sort` and `uniq`
- Processes, disk and memory
- Archives, networking, packages and services
- Cron scheduling and logs
- Interview questions with short answers
